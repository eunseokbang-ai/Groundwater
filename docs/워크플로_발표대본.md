# 드론 기반 암사면 분석 워크플로 — 발표 대본 (20쪽)

PPT 발표자 노트 칸에 바로 붙여 넣을 수 있도록 장당 3~5줄로 썼습니다. "(질문 대비)" 줄은 필요할 때만 쓰시면 됩니다.
쪽 번호는 `docs/워크플로_발표자료.pdf` 기준입니다.

---

### 1쪽 — 드론 기반 암사면 분석 워크플로 (전체 개요)
```
WBS 2-1 절리대 파악 결과를 2-4 타겟 그라우팅 설계 입력으로 넘기는 전체 흐름.
① 취득(근접비행·RGB·라이다·열화상) → ② 처리(점군·정사영상·좌표 정합) → ③ 프로그램 분석 → ④ 해석·활용.
③ 분석 프로그램은 구현 완료, 반구대 암각화 암벽 실자료로 사전 검증. 라이다·열화상 융합은 개발 예정.
강우 전후, 그라우팅 시공 전후 반복 촬영으로 효과 검증까지 이어짐.
```

### 2쪽 — ① 입면 근접비행 방식
```
사람이 접근하기 어려운 수직 암벽을 정면에서 약 20 m 이격, 카메라 수평으로 촬영.
정면 + 경사 ±20° 추가 촬영으로 오버행·절리면 그늘 보완.
사진 중복 진행 방향 80%, 스트립 사이 70%.
(질문 대비) 이격 거리는 해상도(GSD)와 비행 안전의 절충 — 방지망·돌출부에 따라 현장 조정
```

### 3쪽 — ① 조사 범위 — 매립지 전체 둘레
```
정면 암벽만이 아니라 매립지 둘레 전체가 대상.
유입부(남·동·서 암벽): 드론으로 절리, 열화상으로 용출 확인.
우회 유출(차수벽 양 끝 바깥 사면), 하류(서북쪽 골짜기)까지 유출 경로를 따라 확인.
과거 영상 1973~2025로 굴착·매립 이력과 원지형도 함께 봄.
(질문 대비) 하류 차수벽 위치는 DTM 추정, 우물은 배치도 정합 — 현장 확인 필요
```

### 3쪽 (서브) — 같은 범위를 0.5 m 드론 DTM 컬러 음영기복도로
```
같은 지도를 드론 DTM 음영기복도로 바꿔 보면 지형이 드러남.
매립지를 둘러싼 절벽, 동쪽 절벽 너머 골짜기, 동쪽 채석장 벤치가 보임.
매립지로 모이는 빗물 4.9 ha — 분수계는 둘레 절벽 상단.
```

### 4쪽 — ① 현장 여건 대응
```
낙석방지망·식생·붕락면이 자료 품질의 주요 장애.
식생은 평면성 필터로 자동 제외(구현). 방지망은 라이다 다중반사로 일부 투과, 마스킹은 개발 예정.
붕락면은 근접 추가 촬영으로 신뢰도 높은 절리면 확보.
가려진 구간은 추정하지 않고 '평가 불가'로 표시.
```

### 5쪽 — ① 센서별 촬영 설정
```
같은 벽면을 세 센서로 촬영해 서로 보완.
RGB(P1 35 mm): 이격 20 m에서 GSD 약 2.5 mm, RTK 촬영 → 절리 형상.
라이다(L3 / Vx15): 모든 반사 기록 → 방지망 뒤 암면 복원.
열화상(H20T): GSD 약 1.8 cm, 일출 전·흐린 날, 강우 후 재촬영 → 용출부.
```

### 6쪽 — ① 열화상 촬영 시각 · 현장 보조자료
```
열화상은 촬영 시각이 결과를 좌우. 낮에는 일사 영향이 커서 암면 온도가 뒤섞임.
지하수 수온은 거의 일정 → 새벽에 유출부 온도 차가 가장 뚜렷(계절에 따라 따뜻하게 또는 차갑게).
보조자료: RTK·GCP(RGB·열화상 겸용 표적), 수온·기온·습도·방사율, 현장 절리 실측, 강우 이력.
DEM 습윤지수로 열화상 우선 촬영 지점을 미리 고름.
```

### 7쪽 — ② 자료처리 흐름
```
센서별 원자료를 상용 소프트웨어로 처리.
RGB: SfM 정렬·GCP → 점군·메시·정사영상(Pix4D·Metashape).
라이다: 궤적 처리(RTK·IMU) → 점군·노이즈 제거(DJI Terra 등).
열화상: R-JPEG → 온도(°C), 방사율·기온·습도 보정.
(질문 대비) 소프트웨어는 예시, 보유 SW로 대체 가능
```

### 8쪽 — ② 보조자료 — 과거 영상 · DEM 지표수
```
과거 영상 20개 시기(항공사진 9 + 정사영상 11)를 자동 정합해 뷰어로 통합.
매립지 지표 유역 7.0 ha(DEM 5 m 원지형), 현재 지형(0.5 m)으로는 4.9 ha(둘레 절벽 상단까지).
지표 유출 경로: 서북쪽 골짜기 → 큰 강 → 금강 방향.
습윤지수로 물이 모이는 곳을 찾아 열화상 우선 지점으로 사용.
(질문 대비) 지표수만 해석한 것 — 지하 흐름은 관측정·ERT로 확인
```

### 9쪽 — ② 좌표 정합 · 품질관리
```
모든 자료를 하나의 좌표계로 맞춘 뒤 프로그램에 입력.
RTK·GCP 공통 좌표계, 벽면 평행 정사영상·DSM과 점군 정합은 구현.
라이다↔사진 점군, 열화상↔RGB 정합은 개발 예정.
품질관리: 점 간격, 정합 잔차, 방지망·식생 구간 기록.
현장 폴더에 넣으면 점군·메시·타일 모델·정사영상·실측 CSV를 자동 인식.
```

### 10쪽 — ③ 프로그램 분석 파이프라인
```
점군에서 절리를 찾아 물길 후보와 그라우팅 설계까지 10단계를 한 번에 처리.
1~5: 입력·식생 제외 → 법선·평면성 → 절리군(스테레오넷 밀도 피크) → 절리면 분리 → 벽면 좌표 전개.
6~8: 입면 트레이스(사진·DEM 6종 검출) → 유출 가능성·안정성 → 절리망 기반 그라우팅 설계.
9 현장 실측 검증까지 구현, 10 라이다·열화상 융합은 개발 예정.
검증: 자동 테스트 58종, 합성 벽면 방향 오차 1° 미만, 반구대 실자료 6.5억 점 전 과정 시험.
```

### 11쪽 — ③ 사전 검증 — 반구대 암각화 암벽
```
익산 자료 전에 실제 드론 자료로 프로그램 전 과정을 시험한 사례.
반구대를 고른 이유: 수직 암벽·식생·오버행·넓은 틈 — 익산과 비슷한 어려운 조건.
자료: 점군 6.5억 점(점 간격 0.3 cm), 벽면 평행 정사영상·DSM 2.83 mm, 메시, 타일 모델.
전체 분석 4.5분(6.5억 점 읽기부터 결과 저장까지), 화면 반응 0.1~0.3초.
현장 특화 기능으로 암각화 실측도를 정사영상·DSM·타일 모델 제자리에 수 cm 정합해 겹침.
```

### 12쪽 — ③ 사전 검증 — 절리군 · 입면 트레이스
```
3차원 절리군 3개: Set 0 층리(15°/296°, 파랑), Set 1 급경사 절리(78°/292°, 빨강), Set 2 벽면 평행(89°/152°, 초록).
왼쪽 두 번째 = 극점 밀도 지도(Kamb 평활 σ3): 진할수록 극점이 모인 곳 — 세 절리군이 뚜렷한 세 집중으로 분리됨, Set 1 집중은 벽면 방향 쪽으로 길게 퍼짐.
사진·DEM에서 트레이스 577개(414 m) 추출 → 방향군 2개로 묶임, 연결된 3차원 절리군과 같은 색으로 표시.
연결 = 각 절리군이 이 벽면을 자를 때 생기는 '예상 각도'와 방향군 각도 비교(15° 이내): F0 173° ↔ Set 0 예상 174°(1° 차이, 확실).
F1 102°는 Set 1 예상 115°와 Set 2 예상 117°가 거의 같아 각도만으로 구분 불가 → 'Set 1 또는 2'로 표시(색은 Set 1).
색은 스테레오넷·트레이스·절리군 지도·단면·3D 모두 같은 규칙(프로그램과 동일).
3D 점군과 2D 영상이 서로 독립적으로 같은 절리 체계를 가리킴 = 교차검증.
측점 33~35 m의 넓은 그늘 틈도 사진+DEM 넓은 틈 검출기로 추적.
(질문 대비) Set 2는 대부분 벽과 평행해 트레이스로는 잘 안 보임 — 3D 점군으로만 잡히는 절리군 (벽을 비스듬히 자르는 일부 Set 2 면만 F1과 같은 각도의 선을 만듦)
```

### 13쪽 — ③ 사전 검증 — 주요 절리면 구조 (암반 내부)
```
절리 하나하나가 아니라, 절리군마다 나란히 놓인 여러 주요 절리면을 골라 암반 블록 끝까지 연장한 거시 구조.
한 절리군은 같은 방향의 면이 몇 m 간격으로 나란히 반복됨 → 같은 평면 위에 놓인 노출면·트레이스를 모아 합친 길이(근거)가 10 m 이상이고 서로 1.5 m 이상 떨어진 면을 모두 그림.
이 구간: Set 0 3개, Set 1 4개, Set 2 2개 (같은 색 = 같은 절리군, 글자표 = 가장 긴 면, Set 1-①은 59 m 근거).
측점 24~40 m, 암면 뒤 8 m 블록: 층리(Set 0)는 완경사로 안쪽으로, Set 1은 급경사로 암반을 관통.
블록 그림은 실제 평면 좌표(벽 방향을 가로로 돌린 지도, 직선 거리) — 평면인 절리는 그대로 평면으로 보임.
검은 선 = 주요 절리면끼리 만나는 교선 — 물이 모여 흐를 수 있는 선형 통로 후보.
오른쪽 세 단면 = 대시보드 '단면으로 보기'와 같은 그림: A 수평 단면(표고 88 m), B 벽면 평행 단면(암면에서 2 m 안쪽), C 횡단면(측점 32 m).
각 단면의 검은 파선과 글자표(A·B·C) = 다른 단면이 그 단면을 자르는 곳 → 세 단면이 서로 어디인지 바로 연결해 읽음. 블록 그림의 파선 사각형 = A·C 위치.
A: Set 1이 암면에서 안쪽으로 비스듬히 들어감. B: 2 m 안쪽에서도 Set 1이 연직에 가깝게 이어지고 하부는 층리(Set 0). C: 층리와 Set 1이 표고 80 m 부근에서 교차.
연장 부분은 해석이므로 시추·ERT로 확인.
(질문 대비) 벽 기준선이 꺾이는 곳에서 측점 기준(펼친) 좌표로 그리면 평면 절리가 휘어 보임 → 실제 평면 좌표가 기본
(질문 대비) 대시보드에서 절리군마다 최대 평면 수(1~10), 근거 길이 최소, 평면 간 최소 간격, 구간, 블록 깊이, 좌표 방식을 바꿔 볼 수 있음 (1개로 두면 가장 단순한 거시 구조)
```

### 14쪽 — ③ 사전 검증 — 유출 가능성 · 안정성
```
절리 밀도·개구·연결성·절리 옆 식생을 합쳐 암면 1 m 격자마다 물길 가능성 점수.
'상'(상위 15%) 구역 20곳, 상위 5곳은 측점 12~58 m 벽 하부(표고 77~85 m).
오른쪽 위 = 파괴 가능 구역: 벽면을 1 m 셀로 나눠 셀마다 그 자리 벽면 방향(입면 깊이에서 구함)과 2 m 안에서 관측된 절리군으로 Markland 시험.
암면 셀 중 전도 66%, 쐐기 29%, 평면 14%가 운동학적으로 가능 — 진할수록 여러 형태가 겹침(측점 20~50 m, 표고 85~100 m).
아래 = 평사투영(벽 대표 85°/321°, 마찰각 30°): 위험 영역에 든 극점·교선 비율 평면 12%, 쐐기 4%, 전도 33%.
주 원인은 Set 2(89°, 벽면과 평행): 급한 벽면에서 판상 전도가 거의 어디서나 가능. 쐐기는 Set 1 × Set 2, 평면은 Set 1(벽면이 292° 쪽으로 향한 곳).
5 m 구간 평균으로 보면 전도 11구간(Set 2), 쐐기 5구간(Set 1 × Set 2) — 셀 지도는 돌출부·오버행까지 각자 판정.
판정은 일반적인 Markland 방식: 절리군을 측정된 방향(평균 경사·경사방향) 그대로 판정.
평사투영 % = 대표 벽면 하나에 대해 위험 영역에 든 절리(극점·교선)의 비율, 셀 지도 % = 셀마다 그 자리 벽면과 근처 절리군으로 다시 판정한 암면 면적 비율 — 계산이 서로 독립.
(질문 대비) 운동학 검토는 '가능성' 선별 — 점착력·수압은 미고려, 정밀 해석은 별도
```

### 14쪽 (서브) — ③ 사전 검증 — 유출 가능성 네 지표
```
14쪽 점수를 이루는 네 지표를 하나씩, 올린 고해상도 벽면 평행 정사영상(2.83 mm) 위에 그린 것.
종합 점수 = 0.30 절리 밀도 P21 + 0.25 열린 정도(홈 평균 깊이) + 0.25 연결성(이어진 트레이스망 길이) + 0.20 절리 옆 식생 — 각 지표는 암면 셀의 5~95 백분위로 0~1.
낮은 값은 거의 투명하게 그려 사진이 보이고, 높은 값만 진하게 드러남. 흰 상자 = 점수 상위 5개 '상' 구역(번호 = 점수 순).
#4·#5(측점 47~58 m 하부)는 절리 밀도와 연결성이 함께 높음 — 여러 지표가 겹치는 곳이 확실한 후보, 한 지표만 높은 곳은 그 이유를 현장에서 확인.
대시보드: 바탕(입면 영상/정사영상)과 표시할 값(등급·점수·지표 하나씩)을 고르고, 새 창에서 확대하며 셀마다 네 값을 확인, 실사 타일 모델 표면에도 같은 지도.
(질문 대비) 절리 옆 식생은 물이 있다는 간접 증거 — 열화상·현장 유출 확인으로 보완 예정
```

### 15쪽 — ③ 사전 검증 — 절리망 기반 그라우팅 설계
```
표면 절리를 암반 속으로 연장(트레이스 길이 ×2)하고, 물길 '상' 절리를 가장 많이 지나도록 공 위치·방향·경사를 고름.
메시로 공이 암반 밖으로 빠져나가는지 검사, 3차원 장면과 실사 타일 모델로 확인.
비교: 표적 천공 30공·240 m → '상' 절리 42% 관통 (104/247).
얕은 균열 주입 41공·85 m → 40개, 균등 수평공 59공·885 m → 1개.
같은 시공량이면 절리망을 따라 배치하는 것이 훨씬 효율적.
(질문 대비) 균등 수평공이 1개뿐인 이유: 물길 절리 위치와 무관하게 벽 전체에 고르게 배치되어 '상' 절리를 거의 만나지 않음
```

### 16쪽 — ③ 사전 검증 — 교훈과 익산 적용 준비
```
실자료 시험으로 찾아 고친 것: 가짜 긴 트레이스, 놓친 넓은 틈, 꺾인 벽면의 입면 잘림, 대표 벽면 하나로는 꺾인·오버행 벽을 못 봄(→ 1 m 셀별 운동학 판정),
그리고 하천 수면(159 m²)·마른 잎이 절리면으로 잡힌 문제 → 벽 아래 바닥·수면 면 22개, 식생 위 면 49개를 자동 제외
(Set 0 층리 평균이 8°→15°로 바로잡힘: 거의 수평인 수면이 평균을 끌어내리고 있었음).
속도: 분석 12분 → 4.5분, 화면 반응 2초 → 0.2초.
보기: 큰 지도·단면·3D는 새 창에서 확대(본 화면은 가볍게), 단면끼리 서로의 위치를 표시.
구조: 절리군마다 면 하나만 그리던 것을 나란한 여러 절리면으로 확장(Set 2처럼 벽과 평행하게 반복되는 면까지 암반 속에 표시).
익산 체크리스트: 촬영 → 처리 → 현장 폴더, 벽면 평행 정사영상·DSM + 평면 정의 내보내기, 벽면 기준선 지정.
절리군별 현장 실측 10~20개로 검증, 열화상은 새벽·강우 후 촬영.
→ 익산 자료가 들어오면 같은 절차로 바로 분석 가능.
```

### 17쪽 — ④ 활성 물길 판정 근거
```
절리가 있다고 모두 물길은 아님 → 네 가지 근거를 겹쳐 봄.
A 기하: 피트 쪽으로 기운 절리, 절리 교차선. B 연속성·개구: 유출 가능성 지도(구현).
C 열화상 온도 이상(개발 예정). D 현장·지형 증거: 유출 흔적, 지표 유역, 관측정 수위, ERT 저비저항대.
근거가 겹칠수록 우선순위 높음. 최종 판정은 지질기술자 검토.
(질문 대비) ERT 저비저항은 점토·금속 영향도 가능 → 보조 근거로만 사용
```

### 18쪽 — ④ 후보 목록 → 설계·조사 연계
```
최종 산출물은 후보 목록: 측점·표고·면적·관련 절리군·점수·우선순위.
표 값은 반구대 시험의 '상' 구역 상위 3곳(측점 12~15, 19~21, 33~35 m).
2-4 주입공 위치·방향, 2-3 시추 위치, 2-2 ERT 측선, 3-1 시공 전후 비교에 활용.
열화상 자료가 연계되면 우선순위를 다시 산정.
(질문 대비) 좌표는 측점·표고와 함께 국가 좌표(X·Y·Z)로도 제공
```
